# Topology 1 in Lean

[![Lean](https://github.com/sergunchik/topology-1-lean/actions/workflows/lean.yml/badge.svg)](https://github.com/sergunchik/topology-1-lean/actions/workflows/lean.yml)
[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/sergunchik/topology-1-lean)

The Lean files of *Topology 1*, the second-year course taught by Sergey Galkin in 2026: the
theorems of the course's book, proved in Lean, a language in which a computer checks every
step of a proof.

- **To read them**, start with [`Course/README.md`](Course/README.md): how to read Lean, and
  which file holds which week. Nothing needs installing to read the files on this page.
- **From the book.** [`BOOK.md`](BOOK.md) lists the book's statements proved here, each with the
  Lean theorems that prove it and links to their lines. The book prints the same names, small and
  grey, under each such statement ("Lean: ..."), and each theorem here names its label in the book.
- **Homework.** The proof of a homework appears here once the homework is due. Until then its
  theorem is stated, its proof reads `sorry`, and a comment says when the proof will appear.
- The files of weeks 12 and 13 are plans until their lecture, as in the book.

## To run them

Run, Lean shows after each step of a proof what remains to be proved.

**In the browser.** Press the button *Open in GitHub Codespaces* above, then *Create codespace* (a
free GitHub account is enough). VS Code opens in the browser, downloads Mathlib, Lean's library of
mathematics, and checks the course's files; the first time this takes several minutes. Then open a
file in `Course/` and put the cursor on a line of a proof.

**On your computer.** Install [VS Code](https://code.visualstudio.com) and its extension *Lean 4*
([instructions](https://lean-lang.org/install/)). Then, in a terminal:

```
git clone https://github.com/sergunchik/topology-1-lean.git
cd topology-1-lean
lake exe cache get
```

The last command downloads Mathlib already compiled (several gigabytes). Open the folder in VS
Code, then a file in `Course/`. The command `lake build` checks every file.

Lean v4.34.1, Mathlib v4.34.1.

## Who wrote them

No person wrote these files. Every line, code and comments, was generated by AI tools (Claude,
Aristotle) from the course's book; some proofs were found by automated provers, as the files say.
Sergey Galkin, who teaches the course, wrote none of them. Whoever wrote a proof, Lean checks it.
